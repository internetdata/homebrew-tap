# [<img src="https://s3.internetdata.io/internetdata-public/brand/mark.svg" alt="InternetData" height="28"/>](https://internetdata.io/) Homebrew tap

The Homebrew tap for [InternetData](https://internetdata.io)'s official command line tools, `internetdata` and `mmdb`.

```bash
brew trust internetdata/tap
brew tap internetdata/tap
brew install internetdata
```

`brew install mmdb` installs `mmdb` the same way, and `brew upgrade` keeps both current. Homebrew won't load a formula from a third-party tap until you trust it, and without the first line it fails with `invalid syntax in tap!`. `brew trust` arrived in Homebrew 7, so run `brew update` first if it comes back as an unknown command.

The formulas in `Formula/` are generated by the release workflows of the [CLI](https://github.com/internetdata/cli) and [mmdb](https://github.com/internetdata/mmdb) repositories, so don't edit them by hand. Open issues against those repositories rather than this one.
