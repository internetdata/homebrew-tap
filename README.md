# [<img src="https://s3.internetdata.io/internetdata-public/brand/mark.svg" alt="InternetData" width="24"/>](https://internetdata.io/) Homebrew tap

The Homebrew tap for [InternetData](https://internetdata.io)'s official command line interface.

```bash
brew trust internetdata/tap
brew tap internetdata/tap
brew install internetdata
```

`brew upgrade` keeps it current. Homebrew won't load a formula from a third-party tap until you trust it, and without the first line it fails with `invalid syntax in tap!`. `brew trust` arrived in Homebrew 7, so run `brew update` first if it comes back as an unknown command.

The formula in `Formula/` is generated by the [CLI repository](https://github.com/internetdata/cli)'s
release workflow, so don't edit it by hand. Open issues against that repository rather than this one.
